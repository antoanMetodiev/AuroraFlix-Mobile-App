## Само за Android / APK

- [ ] Само arm64 APK (почти всички телефони от последните ~7 години). 32-битовите не се поддържат.
- [ ] **Лимит 25 MiB** на Cloudflare за файл — APK-то с Shorebird е ~24.5 MiB. Ако порасне: Cloudflare R2 или GitHub Releases и смени `url` във `version.json` + линка в `my-app/components/layout/navigation.tsx`.

## Как се пускат обновления

**Малка промяна (само Dart код: екрани, дизайн, логика)** — потребителите не правят нищо:

```
shorebird patch android --release-version=0.3.1+7 -- --split-debug-info=build/symbols
```

Пиши текущата версия от `pubspec.yaml`. Нова иконка (от Lucide/FontAwesome) не влиза в поправка — трябва ново APK; Shorebird го казва с предупреждение за „asset changes“.

Телефонът сваля поправката при пускане и я прилага при следващото отваряне.

**Голяма промяна (нов native пакет, иконка, Android разрешения, нова версия на Flutter)** — ново APK:

1. Вдигни `version:` в `pubspec.yaml` (`+N` винаги расте).
2. `shorebird release android --artifact apk --target-platform android-arm64 --flutter-version=3.47.7 --no-confirm -- --split-debug-info=build/symbols`
3. `node tool/publish_apk.mjs "бележки на български" "notes in English"` — копира APK-то и `version.json` в `my-app/public/downloads/`.
4. Commit + push на my-app → Cloudflare го пуска. Приложението показва „Има нова версия → Обнови“.
